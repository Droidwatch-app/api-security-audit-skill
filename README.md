# api-security-audit

Skill de Claude para auditar APIs (REST/GraphQL/gRPC), apps con LLM, agentes y servidores MCP.
Marcos: OWASP API Top 10 2023, LLM Top 10 2026, Agentic Top 10 2026, ASVS 5.0, NIST SP 800-228, CWE, CVSS v4, PCI DSS, ISO 27001/42001.

## Instalación
- Claude (web/desktop): descarga el `.skill` desde Releases y usa "Save skill".
- Claude Code: copia esta carpeta a `~/.claude/skills/api-security-audit/`.

## Uso responsable
Úsala solo en sistemas propios o con autorización escrita. Ver `references/10-etica-y-reglas-de-compromiso.md`.
